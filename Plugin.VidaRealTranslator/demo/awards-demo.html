What you just saw

Six gates, and the model is the last one.

Each step exists to make the next one smaller. By the time Azure is involved, almost nothing is left — which is the whole economic argument, and the reason the second click felt instant.

STEP 01

Collect

A MutationObserver walks only the subtrees that actually changed — text nodes, plus visible attributes like placeholder, title and aria-label. Full sweeps are kept for load, postback and client-side navigation.

STEP 02

Refuse

Every candidate runs the safeguards. Interface passes; data, secrets, names and grid contents are dropped here and never reach any later stage. This is where the red column stopped.

STEP 03

Ask the browser

localStorage answers in microseconds, keyed by language and normalized text. On a returning device this is where the story ends for nearly every string on the page.

STEP 04

Batch

Misses are normalized identically on both sides — with a hand-built whitespace class, because .NET's idea of whitespace is not JavaScript's — deduplicated, and posted up to 250 at a time.

STEP 05

Ask the database

A SHA-256 lookup against a unique index on hash plus language. One translation per string per language is enforced by the schema, not by hope. Rows marked Excluded resolve to the original, permanently.

STEP 06

Ask the model

Whatever survives goes to Azure OpenAI in chunks of 50, four in parallel. A partial or non-JSON answer is discarded rather than cached: a poisoned cache is worse than an untranslated label.

Safeguards

The hard part was teaching it what not to translate.

A church database is mostly the things you must never hand to a model: members, children, giving, card numbers. So the collector is a whitelist of interface, and anything shaped like data is dropped before a request is ever built.

Anything shaped like a secret

Visa 4487 9x00 xxxx 1071

One masked card once reached the cache. The fix was not a selector, it was a rule: any string carrying masking characters, or eight or more digits, is refused site-wide. No interface label has that many digits.

Names, children first

.js-person-select .checkin-person .family-button

Check-in person lists, family selects and attendee banners are excluded through Rock's stock markup hooks, so an upgrade cannot silently reopen the hole. The Check Out and Save buttons beside them still translate.

Nothing you typed

value  contenteditable  iframe

The script never reads the value of a data input, never enters editable content, and never crosses into an iframe — which puts passwords and the hosted card form structurally out of reach, not merely out of policy.

Never innerHTML

node.nodeValue  setAttribute

Translations are written through text nodes and attributes only, and model output is stripped of markup on the server. A creative answer from a language model cannot become an element on a page used by staff.

Data has a shape

emails  GUIDs  amounts  dates  lava

Grid interiors are skipped wholesale and the rest is caught by shape. A dropdown's options translate only when an administrator has whitelisted that select by name, and the value sent back to the server is never touched.

When in doubt, English wins

catch → keep the original

Missing configuration, a model outage, a truncated response, a broken selector, a full localStorage: every failure path ends the same way. The translator can go down; the church's software cannot.

Operations

One screen, one toggle, no SQL.

Turning it on writes the script tag into the page header of every site in the installation. Turning it off removes it. Everything else lives on one dashboard under Installed Plugins.

  • InstallOne DLL and two scripts, then restart Rock. Plugin migrations create the table, the page and the dashboard block.
  • CorrectA searchable grid to edit any translation or mark it Excluded. Every write bumps a cache epoch, so browsers holding the old wording drop it on their next page load.
  • Budget250 strings per request, 2,000 characters per string, and a ceiling of 5,000 new translations per hour. The counter only counts what was really produced, so an outage cannot lock the site out for an hour.
  • VerifyA Test Connection button that performs a real translation and shows the actual failure reason, plus cards for cached rows, throttle usage, and which sites still run an outdated script version.
  • SwitchThe language tab visitors tap, floating or mounted inside any element you name with a CSS selector. Languages are lines of text — add zh and a label, and Chinese appears in the tab. Choosing the source language shows the original, untouched.
  • ExtendA provider interface with exactly one implementation. Adding another model is a class and a case statement, deliberately not four half-tested integrations nobody asked for.
